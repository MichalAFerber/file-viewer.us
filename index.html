The File Viewer family

View any file, right in your browser

A family of fast, single-file viewers. Drag & drop a file and read it instantly — no build, no uploads, no accounts. Everything runs locally in your browser.

Single-file & offline Files never leave your device Open source

HTML Viewer

html-web-viewer

Fast, single-file HTML viewer — drop an HTML file to render it in a sandboxed iframe, or open CSS/JS/TS/template source with syntax highlighting, line numbers, and a Format/beautify toggle. Offline, no build; deploys to Cloudflare Pages.

GitHub html-viewer.us ↗

Markdown Viewer

markdown-web-viewer

Fast, mobile-first, single-file Markdown viewer. Drag & drop any text file to render it — no build, no uploads, MIT licensed.

GitHub markdown-viewer.us ↗

PDF Viewer

pdf-web-viewer

A fast, mobile-first, single-file PDF viewer. Drag & drop a .pdf anywhere on the page and start reading instantly.

GitHub pdf-viewer.us ↗

EPUB Viewer

epub-web-viewer

A fast, single-file EPUB viewer that runs entirely in your browser — drag & drop a book and read. No build, no uploads, works offline.

GitHub epub-viewer.us ↗

Data Viewer

data-web-viewer

A fast, single-file data viewer — drop a CSV, TSV or JSON file to explore it as a sortable, searchable table. No build, no uploads, works offline.
